## Что вы получаете

Задайте вопрос языковой модели — получите реальные изменения инфраструктуры на вашем сервере FastPanel:

> **Вы:** «Создай новый сайт `foo.example.com` под пользователем `www-root`, PHP 8.4, без базы данных, и подключи наш wildcard SSL-сертификат. Также включи HTTP/2 и HTTP/3.»
>
> **LLM (~30 секунд, 5 вызовов инструментов):** Сайт id 53 запущен по адресу https://foo.example.com с HTTP/2, HTTP/3, wildcard TLS и автоматически настроенным HTTPS-редиректом.

> **Вы:** «Покажи мне конфигурацию nginx для сайта 1 — проверь, блокирует ли она `.env`, `.git` и другие чувствительные пути. Если нет — добавь защиту.»
>
> **LLM:** Читает конфигурацию, обнаруживает, что `.env` и `.htaccess` отдаются как статические файлы (уязвимость безопасности), редактирует frontend-блок, добавляя правила deny для точечных файлов, чувствительных расширений и файлов фреймворков, предварительно просматривает diff через `dry_run`, затем применяет изменения. `.env` теперь возвращает 404; `.well-known/acme-challenge` по-прежнему работает.

> **Вы:** «Какие сайты работают на этом сервере, кто их владельцы и у каких не настроен принудительный HTTPS?»
>
> **LLM:** Запрашивает `sites_list` и сообщает о 5 сайтах без `https_redirect: true`.

## Возможности

- **32 инструмента**, охватывающих сайты, базы данных (включая дамп/импорт по SSH), пользователей, DNS-зоны, SSL-сертификаты, нагрузку на систему, очередь, логи сайтов, планы резервного копирования, диагностику на уровне хоста, загрузку/развёртывание файлов в корень сайта, а также raw-конфигурации nginx/apache/php.ini.
- **Двухтокенная модель безопасности.** Операции чтения используют токен только для чтения; мутирующие операции требуют отдельного токена записи (`FASTPANEL_WRITE_TOKEN`). Если токен записи не задан, каждый инструмент записи завершается с ошибкой.
- **`confirm: true` обязателен** для каждой операции записи. Случайные выводы LLM не могут изменить состояние системы.
- **`dry_run: true` предварительно показывает** точное тело HTTP-запроса, которое было бы отправлено на сервер — пароли скрыты как `***`, сетевой вызов не выполняется.
- **Компактный режим ответа** для sites_list, чтобы избежать переполнения контекста LLM на больших панелях.
- **Журнал аудита в stderr** для каждой выполненной операции записи, с redacted-паролями.
- **Аннотации инструментов MCP** (`readOnlyHint` / `destructiveHint` / `idempotentHint` / `openWorldHint`), позволяющие клиентам и сканерам политик правильно классифицировать каждый инструмент вместо того, чтобы считать диагностику только для чтения разрушительной.
- **Автоматическая проверка `nginx -t` с откатом** — `site_configuration_update` проверяет живую конфигурацию после применения и автоматически откатывает сломанное изменение при настроенном SSH.
- **Протестировано на живой панели FastPanel 2** с более чем 35 сайтами в продакшене.

## Зачем это нужно

FastPanel не публикует спецификацию OpenAPI. Эндпоинты и форматы полезных нагрузок в этом сервере были получены методом обратной разработки из Angular SPA-бандла панели и живых захватов DevTools, включая неочевидные особенности:

- Эндпоинты списков требуют параметров вида `filter[limit]=…&filter[type]=…` — обычный `?limit=…` молча игнорируется.
- Создание сайта — это двухшаговый мастер (`POST /api/master/domain` — зондирование → `PUT /api/master` — фактическое создание), а не стандартный `POST /api/sites`.
- Поле `backend` в конфигурации сайта является конфигом пула PHP-FPM при `handler=php_fpm`, но блоком Apache VirtualHost при `handler=fcgi`.
- Привязка/отвязка SSL проходит через `PUT /api/sites/{id}` (на стороне сайта), а не `POST /api/sites/{id}/certificate` (такого эндпоинта не существует).

Всё это задокументировано в описаниях инструментов, чтобы LLM не приходилось заново это обнаруживать.

## Требования

- Node.js версии 20 или выше
- Установка FastPanel 2, доступная по HTTPS
- Root-доступ по SSH к хосту панели для создания API-токенов (однократно)

## Установка

```bash
git clone https://github.com/iMateo/fastpanel-mcp.git
cd fastpanel-mcp
pnpm install      # или: npm install
pnpm build
```

## Получение API-токенов

На хосте FastPanel (от имени root) создайте токен только для чтения для повседневного использования:

```bash
mogwai users tokens add -n mcp-read -s read_only -e 2030-12-31
```

> Бинарный файл CLI находится по пути `/usr/local/fastpanel2/fastpanel`; в последних сборках FastPanel он доступен в `PATH` как `mogwai` (`/usr/local/bin/mogwai` → тот же бинарник). Старая документация называет его `fastpanel`, который **не** включён в `PATH` — используйте `mogwai` или полный путь. Только для root.

Скопируйте поле `msg` из возвращённого JSON — это ваш токен. Он обходит двухфакторную аутентификацию и не зависит от TTL сессии, поэтому обращайтесь с ним как с серверными учётными данными.

Опциональный токен записи со сроком действия и привязкой к IP:

```bash
mogwai users tokens add -n mcp-write -c <your-ip> -e 2030-12-31
```

Оставьте `FASTPANEL_WRITE_TOKEN` незаданным в конфигурациях, где операции записи не нужны.

```bash
cp .env.example .env
```

```
FASTPANEL_URL=https://panel.example.com:8888
FASTPANEL_TOKEN=<your read token>

```

## Инструменты

### Чтение (токен записи не требуется)

| Инструмент | Эндпоинт | Возвращает |
|---|---|---|
| `sites_list` | `GET /api/sites/list` | Все сайты, по умолчанию 13 основных полей (компактный режим) |
| `site_get` | `GET /api/sites/{id}` | Полный объект сайта из 40 полей (сертификат, backend, резервные копии, статистика) |
| `site_configuration_get` | `GET /api/sites/{id}/configuration` | Raw-конфигурация nginx (frontend), backend обработчика (PHP-FPM или Apache), php.ini |
| `databases_list` | `GET /api/databases` | Базы данных MySQL + PostgreSQL с владельцами и размерами |
| `database_servers_list` | `GET /api/databases/servers` | Доступные серверы БД — используйте их id в `database_create` |
| `users_list` | `GET /api/users` | Пользователи панели и владельцы сайтов |
| `dns_domains_list` | `GET /api/dns/domains` | DNS-зоны (пусто, если DNS панели отключён) |
| `dns_records_list` | `GET /api/dns/domain/{id}/records` | Записи для одной зоны |
| `certificates_list` | `GET /api/certificates` | Сохранённые SSL-сертификаты (LE + кастомные) |
| `system_load` | `GET /api/loads/full` | Загрузка CPU / памяти / диска / средняя нагрузка / топ процессов |
| `queue_list` | `GET /api/queue/list` | Фоновые задачи, включая завершённые |
| `queue_active` | `GET /api/queue` | Только выполняющиеся задачи (завершённые отфильтрованы) + `meta.all_done` для детерминированного опроса |
| `site_logs` | `GET /api/sites/{id}/log/{lines}/{type}` | Хвост access- или error-лога nginx/apache (frontend_/backend_) без SSH |
| `site_resources` | `GET /api/sites/{id}/resources` | Базы данных, поддомены, DNS- и почтовые зоны, привязанные к сайту |
| `backup_plans_list` | `GET /api/v2/backup/plans` | Настроенные планы резервного копирования |
| `me` | `GET /api/me` | Аккаунт, связанный с текущим токеном чтения (имя пользователя, роли, ssh) |
| `settings_get` | `GET /api/settings` | Общепанельные настройки (ОС, лицензия, лимиты, уведомления) |

### Запись (требуется `FASTPANEL_WRITE_TOKEN` + явное `confirm: true`)

| Инструмент | Эндпоинт | Назначение |
|---|---|---|
| `user_create` | `POST /api/users` | Создать нового пользователя панели (владельца сайта) |
| `database_create` | `POST /api/databases` | Создать базу данных MySQL или PostgreSQL с выделенным пользователем БД |
| `site_create` | `POST /api/master/domain` + `PUT /api/master` | Атомарно создать сайт, опционально с пользователем, базой данных и FTP |
| `site_update` | `PUT /api/sites/{id}` | Изменить корень документов (`index_dir`) / индексный файл — например, указать Laravel-сайт на `public/` (пресет `framework: "laravel"`) |
| `site_ssl_update` | `PUT /api/sites/{id}` | Подключить / заменить / отключить SSL-сертификат, включить/выключить HTTPS / HTTP2 / HTTP3 / HSTS |
| `site_backend_update` | `PUT /api/sites/backend/{backend_id}` | Изменить версию PHP, обработчик, порт, сокет, переменные окружения (передаётся id сайта — id backend'а определяется внутренне) |
| `site_configuration_update` | `PUT /api/sites/{id}/configuration` | Заменить raw-конфигурацию nginx/apache/php.ini для сайта. **Опасно**: неверный синтаксис может сломать сайт — при настроенном SSH после применения выполняется `nginx -t` и **автоматически откатывает** изменение при неудаче (передайте `validate: false` для отключения) |
| `certificate_create_letsencrypt` | `POST /api/certificates` | Выпустить новый сертификат Let's Encrypt (асинхронно — опрашивайте `queue_active`) |

### Через SSH (требуется `FASTPANEL_SSH_HOST`)

Эти инструменты делают то, чего не может REST API — они выполняются непосредственно на хосте панели. Подключение опционально и не зависит от хоста: задайте `FASTPANEL_SSH_HOST` (+ опционально `FASTPANEL_SSH_USER`/`PORT`/`KEY`), чтобы указать на **любой** сервер FastPanel. Сервер делегирует выполнение вашему локальному клиенту `ssh`, поэтому хост должен быть доступен с аутентификацией по ключу. `nginx_validate` и `site_doctor` доступны только для чтения; остальные — операции записи (`confirm: true` + предпросмотр `dry_run`).

| Инструмент | Выполняет | Назначение |
|---|---|---|
| `nginx_validate` | `nginx -t` | Проверить живую конфигурацию nginx до/после `site_configuration_update` — обнаружить синтаксические ошибки до того, как они положат nginx |
| `site_doctor` | `stat` / `systemctl` / `nginx -t` | Диагностировать причину ошибок сайта: отсутствующий docroot, родительский каталог без `o+x` (ловушка 750 → 404), отсутствующий FPM-сокет, недоступный backend, сломанная конфигурация nginx |
| `database_dump` | `mysqldump` | Сделать дамп базы данных в `.sql`-файл в staging-каталоге (локальный MySQL). Создаёт файл с правами root — требует `confirm: true` |
| `database_import` | `mysql` | Загрузить `.sql`-файл (из staging-каталога) в базу данных. **Разрушительная операция** — требует `confirm: true` |
| `site_files_upload` | `rsync` (запасной вариант scp) | Загрузить локальный файл/каталог в корень сайта, затем выполнить chown на пользователя сайта. `delete: true` зеркалирует (удаляет файлы, отсутствующие локально) |
| `site_files_deploy` | `git clone` / `curl` + `tar` | Загрузить файлы на хост (https git-репозиторий или tarball) в корень сайта, затем выполнить chown на пользователя сайта |
| `site_file_put` | `cat` через ssh | Записать один небольшой inline-файл (заглушка/.htaccess/robots.txt) в корень сайта, затем выполнить chown на пользователя сайта |

Пути для дампа/импорта ограничены staging-каталогом (по умолчанию `/root/fastpanel-mcp-dumps`, переопределяется через `FASTPANEL_DUMP_DIR`); пути за его пределами или содержащие `..` отклоняются. Три инструмента загрузки/развёртывания определяют `index_dir` сайта и его владельца через `site_get`, отклоняют пути назначения, выходящие за пределы корня сайта или содержащие небезопасные для оболочки символы, и выполняют `chown` на системного пользователя сайта, чтобы nginx/PHP-FPM мог их обслуживать (файлы с правами root вернут 403).

## Примеры использования

**Развернуть тестовый сайт под wildcard-сертификатом (30 секунд, без ожидания DNS/LE):**

```
site_create(domain="foo.example.com", owner_id=2, php_version="84")
  → site_ssl_update(site_id=<new>, certificate_id=<wildcard>, https_redirect=true, http2=true, http3=true)
```

**Развернуть продакшен-сайт с новым сертификатом Let's Encrypt:**

```
site_create(domain="foo.com", aliases=["www.foo.com"], owner_id=<id>, php_version="84", database={...})
  → certificate_create_letsencrypt(site_id=<new>, email, common_name="foo.com")
  → queue_active  # опрашивать до статуса SUCCESS задачи LE
```

**Укрепить стандартный nginx (заблокировать `.git`, `.env`, `.htaccess`, composer.json и т.д.):**

```
site_configuration_get(site_id)
  # LLM вставляет блоки location с правилами безопасности во frontend
site_configuration_update(site_id, frontend=<edited>, backend=<unchanged>, phpini=<unchanged>)
```

**Удалить устаревшие версии TLS:**

```
site_configuration_get(site_id)
  # LLM заменяет "ssl_protocols TLSv1.1 TLSv1.2 TLSv1.3" на "ssl_protocols TLSv1.2 TLSv1.3"
site_configuration_update(site_id, frontend=<edited>, backend=<unchanged>, phpini=<unchanged>)
```

## Модель безопасности

- **Двойные токены.** Токен чтения всегда обязателен. Токен записи опционален — если `FASTPANEL_WRITE_TOKEN` не задан, каждый инструмент записи завершается с ошибкой `FastPanelWriteDisabledError` ещё до обращения к сети.
- **`confirm: true`** — обязательный аргумент для каждого инструмента записи. Инструменты отказываются выполняться без него — это ваш последний рубеж защиты от запутавшейся языковой модели.
- **`dry_run: true`** возвращает точное тело JSON-запроса, который был бы отправлен, с паролями, скрытыми как `***`, полностью пропуская HTTP-вызов.
- **Журнал аудита в stderr** фиксирует каждую выполненную операцию записи с redacted-полезной нагрузкой. В Claude Code это отображается в MCP-логах.
- **Автоматическая проверка `nginx -t`.** При настроенном SSH `site_configuration_update` запускает `nginx -t` сразу после применения и **автоматически откатывает конфигурацию** при неудаче — некорректное изменение не оставит nginx неспособным к перезагрузке. Передайте `validate: false` для отключения.
- **Аннотации инструментов.** Каждый инструмент поставляется с MCP-хинтами `readOnlyHint` / `destructiveHint` / `idempotentHint` / `openWorldHint`, чтобы MCP-клиенты и внешние шлюзы политик могли применять правильные ограничения для каждого инструмента.
- **Инструменты удаления отсутствуют.** Разрушительные операции оставлены для веб-интерфейса до их намеренного добавления.
- **IP-блокировка токенов** (`mogwai users tokens add -c <ip>`), чтобы утёкший токен нельзя было использовать с других адресов.

## Известные особенности

- **Параметры `filter[...]`:** Эндпоинты списков FastPanel ожидают `filter[limit]=…&filter[type]=…`. Обычный `?limit=…` молча игнорируется.
- **Создание сайта — это мастер, а не REST-создание.** Панель выполняет `POST /api/master/domain` (зондирование), затем `PUT /api/master` (фактическое создание), а не `POST /api/sites`. Инструмент `site_create` скрывает эту сложность.
- **Асинхронные операции.** Выпуск сертификата, обновление backend сайта и ряд других операций немедленно возвращают `action: "CREATING"` / `"UPDATING"` и выполняются в фоне. Используйте `queue_active` для опроса.
- **Официальная спецификация OpenAPI отсутствует.** Эндпоинты получены методом обратной разработки. Если новый релиз FastPanel что-то сломает, пожалуйста, создайте issue с описанием новой формы полезной нагрузки.
- **Самоподписанный TLS.** Большинство установок панели используют самоподписанные сертификаты. Задайте `FASTPANEL_INSECURE_TLS=1` или разместите перед панелью корректный сертификат.
- **fail2ban / ограничение частоты запросов.** FastPanel поставляется с fail2ban и ограничением частоты запросов на уровне панели. Тестовые скрипты, активно обращающиеся к API, могут привести к блокировке вашего IP.

- Управление почтовыми доменами и почтовыми ящиками
- Массовые операции (например, «применить это укрепление nginx ко всем сайтам»)
- CLI-резервные инструменты по SSH для операций, недоступных через REST (`transfer`, `firewall save/restore`, `panel ip_match`)
- Структурированный MCP `outputSchema` для типизированного отображения результатов клиентами
- Повторные попытки с экспоненциальной задержкой при учёте ограничений частоты запросов
